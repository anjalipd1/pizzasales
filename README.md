# pizzasales

Pizza Sales Report Dashboard built using Power BI to analyze sales performance, customer ordering patterns, and key business KPIs. The dashboard provides interactive visualizations for revenue trends, top-selling pizzas, and sales insights to support data-driven decisions.

**Features:**
Built a Power BI dashboard analyzing pizza sales data with KPIs such as revenue, orders, and average order value.
Performed data cleaning, transformation, and visualization using Power Query and DAX.
Generated insights on sales trends, best-selling products, and customer preferences.
